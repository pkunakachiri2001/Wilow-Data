# Ngrok Setup Guide

This guide will walk you through the process of setting up a new ngrok account, initializing it on this machine, and updating your project to use the new connection.

## Step 1: Create a New Ngrok Account
1. Go to the [ngrok signup page](https://dashboard.ngrok.com/signup).
2. Create a new account and verify your email.
3. Once logged in, navigate to **Getting Started** > **Your Authtoken** on the left sidebar.
4. Copy the auth token provided on that page.

## Step 2: Initialize Ngrok with Your New Token
Since the `ngrok.exe` executable is already located in this project folder, you just need to link it to your new account.

1. Open a new Command Prompt (or PowerShell) in this directory (`c:\Users\DELL\OneDrive\Desktop\Teensy_Original`).
2. Run the following command, replacing `<YOUR_AUTH_TOKEN>` with the token you copied in Step 1:

```cmd
ngrok.exe config add-authtoken <YOUR_AUTH_TOKEN>
```
*Note: This will save the configuration file on your machine and link `ngrok.exe` to your new account.*

## Step 3: Start Ngrok
You can now start the ngrok tunnel. We have a batch script for this already.

1. Double-click the `start_ngrok.bat` file in this folder.
2. Alternatively, run the following command in your terminal:
```cmd
ngrok.exe http 5000
```
3. A terminal window will open displaying your active tunnel status. Look for the line that says **Forwarding**. It will look something like this:
   `Forwarding                    https://1a2b-3c4d-5e6f.ngrok-free.app -> http://localhost:5000`

4. Keep this terminal window open! If you close it, the tunnel will stop.

## Step 4: Update the Raspberry Pi Client
The URL generated by ngrok changes every time you restart it (unless you have a paid plan with a static domain). You need to update the client script so it knows where to send the data.

1. Copy the **Forwarding** URL from the ngrok terminal (e.g., `https://1a2b-3c4d-5e6f.ngrok-free.app`).
2. Open `rpi_client.py` in your text editor.
3. Locate line 12:
   ```python
   REMOTE_SERVER_URL = "https://YOUR_NGROK_ID.ngrok-free.app/upload"
   ```
4. Replace the string with your new forwarding URL, and **make sure to keep the `/upload` at the end**.
   ```python
   REMOTE_SERVER_URL = "https://1a2b-3c4d-5e6f.ngrok-free.app/upload"
   ```
5. Save the `rpi_client.py` file and restart your Raspberry Pi client for the changes to take effect.
